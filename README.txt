JASUU MASII — JANMASHTAMI WEBSITE

Files:
- index.html
- images/jasuu-1.jpg ... images/jasuu-10.jpg

To test:
1. Keep the images folder beside index.html.
2. Double-click index.html to open it in Chrome.

To publish on GitHub Pages:
1. Create a GitHub repository.
2. Upload index.html and the images folder.
3. Settings -> Pages -> Deploy from branch -> main / root.
4. Open the generated Pages link on the phone.

Music:
The page includes a lightweight browser-generated divine ambience so it works without an audio file.
If you have a specific Janmashtami song, replace this later with your audio file.
